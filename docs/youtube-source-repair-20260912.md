# YouTube 원본 집계·영상 연결 복구 — 2026-09-12

## 원본에 반영한 변경

- 실제 반환된 조회·참여 일별 데이터의 공통 연속 구간을 집계 종료일로 사용한다.
- D7은 D0–D6 전체 일별 범위와 별도 조회/참여 총합이 확보된 경우만 완료한다.
  API 오류·미제공 날짜를 0이나 완료로 만들지 않는다. 음수 참여 조정값은 보존한다.
- 원본 수집기의 검증된 D7은 이후 시트 수입으로 덮어쓸 수 없다. 다른 발행일의
  오래된 D7 창은 완료 모집단에서 제외한다.
- 실제 라이브 메타데이터로 LIVE를 유지한다. P0D 길이만으로 SF에 편입하지 않는다.
- 누락된 공개 영상 8건을 정확한 채널·공개 상태·발행일로 DB에 등록했다.

운영 수집기 관련 회귀 67개를 통과했고, 설치된 코드를 실제 API와 운영 DB에서
수동 실행·재조회했다. 인증·예약 주기·gateway·1P/3P 분류는 변경하지 않았다.

## 대시보드 재발 방지

- 전체 발행을 LF+SF로만 제한하던 검증을 포맷별 원본·렌더행·품질 집계의 대조로
  교체했다. LIVE를 LF/SF 분모에 넣지 않으며 상세 KPI에 LIVE 수를 명시한다.
- Analytics 일별 요청은 원본 수집기와 동일하게 `maxResults=10000`을 사용한다.
  실제 대조에서 이 옵션을 생략하면 8월 LIVE의 마지막 0값 날짜가 추가 반환되어
  D7 완료 여부가 달라졌다. 원본과 동일한 보수적 완료 판정을 유지한다.
- 일시적 API 오류는 SDK 최대 2회 재시도하며 실패를 성공으로 숨기지 않는다.

코드/셀만 복원한다. 원본 DB 전체를 자동 덮어쓰지 않는다.
